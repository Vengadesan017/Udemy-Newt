# JPA Caching
- level
  - data request( persistenceCOntext) --> first level caching --> second level caching --> data base
- Transaction
  - each transaction ae work in each persistenceContext ex1 2 3
  - all PC on the second level cache
  - second level caching is on the database
## First Level caching
- in same transactional if you try to read the same data but it fetch from cache memory for second time
## First Level caching
- add dependency like hibernate-ehcache from org.hibernate
- mentio ehcache in application properties
  ```
    # Second Level Cache - Ehcache
    
    #1. enable second level cache
    spring.jpa.properties.hibernate.cache.use_second_level_cache=true
    
    #2. specify the caching framework - JCache
    # https://northcoder.com/post/setting-up-hibernate-with-jcache-an/
    spring.jpa.properties.hibernate.cache.region.factory_class=org.hibernate.cache.jcache.internal.JCacheRegionFactory
    #3. Only cache what I tell to cache.
    spring.jpa.properties.jakarta.persistence.sharedCache.mode=ENABLE_SELECTIVE
    
    logging.level.net.sf.ehcache=debug
    
    #4. What data to cache?
  ```
- mention @Cacheable in entity you needed
- then it use second level cache to retrive the data like
   1. read all data for find all
   2. findById it use cache ddata


 # Hibernate Tips
1. Soft delete
   - add isDeleted Attributed as boolean in model
   - deleteBY ID
     - mention the model as @SQLDelete(Sql="update cource set is_Deleted = true where id = ? ")
   - Find By ID
     - mention the model as @Where(clause="is_Deleted = false")
     - but it not work in nativ query
       - so manually add the condition
     - but this data is not updated in cache
       - so prebook the isdeleted column
       - @preRemove private void preRemove(){this.isDeleted = true;}
2. Embeddable in the column
   - like address in top model
   - create bottom model with state city area and mention as @Embeddable
3. Enums
   - create enum like a class with the data
   - use this enum typpe in column in model and mention as @Enumerated
