- flow
  1. client
  2. spark context
  3. Dag schedular (graph) - task schedular
  4. communication ditbeen cluster master and spark context for requesting resource
  5. cluster manager allot the executer in worker node
  6. now the spark context and worker node are communication to perform operation

### shared Variables
- Broadcast
  - Broadcast variables allow the programmer to keep a read-only variable cached on each machine rather than shipping a copy of it with tasks
  - Immutable
```
days={"sun": "Sunday", "mon" : "Monday", "tue":"Tuesday"}
bcDays = spark.sparkContext.broadcast(days)
bcDays.value
bcDays.value['sun']
```
