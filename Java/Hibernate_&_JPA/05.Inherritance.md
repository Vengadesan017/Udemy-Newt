# Inheritance in entity
- to calculate the salary for emplyee based on type of employee
  - use abstract employee class
  ```
    @Entity
    public abstract class Employee {
    
    	@Id
    	@GeneratedValue
    	private Long id;
    
    	@Column(nullable = false)
    	private String name;
    
    	protected Employee() {
    	}
    
    	public Employee(String name) {
    		this.name = name;
    	}
  ```
  - inherit ans full time and partime
    - create attribute and create constructor for name and salary
    ```

      @Entity
      public class FullTimeEmployee extends Employee {
      	protected FullTimeEmployee() {
      	}
      
      	public FullTimeEmployee(String name, BigDecimal salary) {
      		super(name);
      		this.salary = salary;
      	}
      
      	private BigDecimal salary;
      
      }
    ```
  - TO insert the data call FullTimeEmployee(name,salary) or PartTimeEmployee(name,salary)
  - mapping
    - to makesingle table for both the full time and part time use `@Inheritance(strategy=InheritanceType.SINGLE_TABLE)` in below to @entity in employee table
      - to show the employee type in single_table use ` @DicriminatorColumn(name="emplyeeType") ` below to strategy to show by the value
    - to make Seperate table for both the full time and part time use `@Inheritance(strategy=InheritanceType.TABLE_PER_CLASS)` in below to @entity
      - it divided a employee table into two seperate table like partitioning
    - to make Seperate table for both the full time and part time and also for employee use `@Inheritance(strategy=InheritanceType.JOINED)` in below to @entity
      - the value are return after the joining
    - @MappedSuperClass insead of Entity, Strategy
      - but we need to manually map the data
