11. Repartition
    - does a full shuffle
    - Preferable used to increase number of partitions.
    - Repartition creates new partitions and does a full shuffle
    - Repartition results in roughly equal sized partitions.
    ```
    ord = sc.textFile('practice/retail_db/orders')
    ord.glom().map(len).collect()   // show the parition
    ord = ord.repartition(5)
    ord.glom().map(len).collect()
    ```
11. Coalesce
    - avoid a full shuffle
    - Preferable used to decrease number of partitions.
    - uses existing partitions to minimize the amount of data that's shuffled
    - Coalesce results in partitions with different size of data.
    ```
    rdd = sc.textFile('practice/retail_db/orders')
    rdd.getNumPartitions()
    rdd.coalesce(1).getNumPartitions()
    ```
