# Spring JPA
- create a repo as interface which extends the JpaRepository<YourModel, pk_type>
  - this interface already contain the predifined repo functions like
    - finfById()  return type optional
    - isPresent()
    - save()
    - saveAll
    - existsById()
    - findAll()
    - findAllById(iter)
    - count()
    - deleteById9id0
    - delete(T)
    - deleteAll(iter)
    - deleteall()
### to sort
- create obj od Sort from Sort.Direction.Desc with the field name
- pass the obj to findAll() method
### to paginate
- create obj for PageResquest with PageResquest.of(0,3)
- pass the obj to findAll() method
### Custom queries
- Use @QUERY("SQL...") with return type as list with model type
