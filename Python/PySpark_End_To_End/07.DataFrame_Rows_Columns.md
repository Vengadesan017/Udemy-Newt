# Dataframe
- the data set is organized into named column / row;
- dataframe = dataset + schema
- source
  - hive
  - csv, json..
  - Cassandra
  - python data frame
  - RDBMS
  - RDDs
- Features
  - distributed
    - create multiple paritition and partition manage to multipke m task and execute in worker node
  - lazy evaluation
    - execution is stated when the trigger is triggered
      - waiting for action and then load the file to process till hold the operation
  - immutable
    - create a differenct stage for upadated data not overrideing gthe data in same stage
  - used in spark ecosystem
    - single api call for spark sql, spark stream, mlib , grapx
  - polyglot
    - support scala, python , java R ...
  - work on huge collect of dataset
    - use wide range of files
  - support both structure and semi
- Organization of data
  - 3 level of organization
    - schema
      - dataset of rows
      - each column is named and typed
    - storage
      distributed to partition
    - api
      - call to process the data
  - StorageLevel(useDisk, useMemory, useOffHeap, deserialized, replication=1)
  ```
  from pyspark import StorageLevel
  df = spark.range(10)
  df.rdd.persist(). getStorageLevel()
  df.rdd.persist(StorageLevel.MEMORY_AND_DISK_2). getStorageLevel()
  ```

# Column 
- use model pyspark.sql.Column
```
from pyspark.sql.functions import col
ord = spark.read.load('practice/retail_db/orders', format='csv', sep=',' ,schema=('order_id int,order_date timestamp,order_cust')
ord.select(col("*")).show()

ord.select(.order_id.alias("orderId")).show(5)
ord.select(ord.order_id.cast("string"))
ord(ord.order_id.between(10,20)).show()
ord.where(ord.order_id.between(10,20)).show()

ord.where(ord.order_status.contains('CLOSED')).show()
ord.where(ord.order_status.like('%LO%')).show()
ord.where(ord.order_status.isin('CLOSED','PENDING')).select(ord.order_status).distinct().show()

from pyspark.sql import Row
df1 = spark.createDataFrame(( Row(id=1, value='foo'), Row(id=2, value=None) ))
df1.select( df1('value') == 'foo', df1('value').eqNullSafe('foo'), df1('value').eqNullSafe(None)).show()

-- like wheere
from pyspark.sql.functions import when
ord.select(ord.order_status,
when(ord.order_status == 'PENDING_PAYMENT', 'PP')
.when(ord.order_status == 'CLOSED', 'CL')
.when(ord.order_status == 'COMPLETE', 'CO')
.when(ord.order_status == 'PROCESSING', 'PR')
.otherwise(ord.order_status).alias("order_status2")).show(10)
```
