# Performance
1. Create indexes
   - right indexes on db
   - execution plan
2. caching
   - first level caching
   - second level caching
   - distributed caching
   - carefull on size of first level caching
3. Eager and Lazy Fetching
   - use lazy mostly
   - eager is default to ToOne mapping
4. Avoiding n+1
   - when read the data in for loop
   - use lazy fetch
   - use entity graph and named entity graphs and dynamic entity graphs
   - use join fetch clause to reduce the db read
