## ACID Property
- Atomicity
- Consistency
- Isolation
- Durability
#### Non repeatable vs phanthom vs Dirty read
- Dirty read
  - simultaniously read and write the data\
- non repeatable
  - read data
  - update data
  - again read data // differenct value are shown
- Phanthom read
  - read data
  - insert data
  - again read data // differenct no rows shows
### Isolation level ( p -> posible , s - > solved)  ( lock the row to maintain  the consistency)
- read uncommited --> dirty p , repeat p , phanthom p
- read commited   --> dirty s , repeat p , phanthom p
- repeatable read --> dirty s , repeat s , phanthom p
- serializable    --> dirty s , repeat s , phanthom s
