# Variables
### Variable Types
- Scalar
  - holds a single value, such as a number, string, or boolean
  - int , float, string, Boolean, CHAR(), VARCHAR(), Binary_FLOAT, DATE...
- Reference
  -  holds the memory address or reference to an object or data structure, rather than the actual data itself
  -  object
- Large Object
  - store large amounts of data such as multimedia files (images, audio, video) or large text data (documents, logs)
  - BLOB, CLOB, NCLOB
- Composite
  - store multiple values or data types within a single variable
  - array , list , record
### Variable naming rules
- must letter with _ # $
- max 30 char
- not a reserved word
### Naming conversion
- variable - v_salary, V age
- cursor - cur_
- Exception e_
- Procedure - p_
- Bing variable - b_

### Declaration
- v_name [COnstant] datatype [not null] [;= default value|expression]
