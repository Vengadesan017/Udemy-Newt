# Variables
### Variable Types
- Scalar
  - holds a single value, such as a number, string, or boolean
  - int , float, string, Boolean, CHAR(), VARCHAR(), Binary_FLOAT, DATE...
- Reference
  -  holds the memory address or reference to an object or data structure, rather than the actual data itself
  -  object
- Large Object
  - store large amounts of data such as multimedia files (images, audio, video) or large text data (documents, logs)
  - BLOB, CLOB, NCLOB
- Composite
  - store multiple values or data types within a single variable
  - array , list , record
### Variable naming rules
- must letter with _ # $
- max 30 char
- not a reserved word
### Naming conversion
- variable - v_salary, V age
- cursor - cur_
- Exception e_
- Procedure - p_
- Bing variable - b_

### %TYPE Attibute
- declare a variable with the same data type as a column or other %TYPE Variable
```sql
declare
V_TYPE employees.JOB_ID%TYPE;
V_TYPE2 V_TYPE%TYPE;
begin
v_type := 'IT_PROG';
v_type2 := 'SA_MAN';
dbms_output.put_line(v_type);
dbms_output.put_line(v_type2);

end;

```

### scope
- like nexted block
```sql
begin <<out>>
DECLARE
  v_text  VARCHAR2(20) := 'Out';
BEGIN 
  DECLARE
    v_text  VARCHAR2(20) := 'In-text';
    v_inner VARCHAR2(30) := 'Inner Variable';
  BEGIN
      dbms_output.put_line('inner -> ' || v_text);
      dbms_output.put_line('outer -> ' || outer.v_text);
  END;
  dbms_output.put_line(v_text);
END;
END ou;
```
### Binding
- bind value to the variable at run time
- placeholder, set at runtime
```sql
declare
VARIABLE v_name VARCHAR2(50);
VARIABLE v_age NUMBER;
begin
 :v_name := 'Ramesh';
 :v_age := 30;
dbms_output.put_line(v_name);
dbms_output.put_line(:v_age);
end;

```
