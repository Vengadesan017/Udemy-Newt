# Dataframe
- the data set is organized into named column / row;
- dataframe = dataset + schema
- source
  - hive
  - csv, json..
  - Cassandra
  - python data frame
  - RDBMS
  - RDDs
- Features
  - distributed
    - create multiple paritition and partition manage to multipke m task and execute in worker node
  - lazy evaluation
    - execution is stated when the trigger is triggered
      - waiting for action and then load the file to process till hold the operation
  - immutable
    - create a differenct stage for upadated data not overrideing gthe data in same stage
  - used in spark ecosystem
    - single api call for spark sql, spark stream, mlib , grapx
  - polyglot
    - support scala, python , java R ...
  - work on huge collect of dataset
    - use wide range of files
  - support both structure and semi
- Organization of data
  - 3 level of organization
    - schema
      - dataset of rows
      - each column is named and typed
    - storage
      distributed to partition
    - api
      - call to process the data
  - StorageLevel(useDisk, useMemory, useOffHeap, deserialized, replication=1)
  ```
  from pyspark import StorageLevel
  df = spark.range(10)
  df.rdd.persist(). getStorageLevel()
  df.rdd.persist(StorageLevel.MEMORY_AND_DISK_2). getStorageLevel()
  ```
